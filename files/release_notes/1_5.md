## New and Improved

- **Trimming Whitespace**. The validator now automatically removes any leading or trailing whitespace when reading spreadsheet cells.

- **New Warnings for Missing Relationships**
    - A warning is now shown when a sample is not associated with a file.
    - A warning is now shown when an experiment is not associated with a metagenome or genome.

- **Manual Update**. The user manual has been updated to include the new errors and warnings.

- **New Developer Guide**. A new guide is now available, explaining the validator's design and architecture for developers.

## Fixes

- **Missing dataset_id Detection**. The validator no longer crashes when a required field such as dataset_id is missing. It now handles this case gracefully.
