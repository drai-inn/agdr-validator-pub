description: "AGDR Validator release notes for version 1.6"
---

## New and Improved

- **Downloadable executables**. The validator is now published as a standalone
  executable for Windows and macOS, so it can be run without installing Python
  or any dependencies. See the Downloads section below.

- **Updated AGDR dictionary**. The validator now uses the `2025_09_01` version of
  the Gen3 dictionary.

- **Multiple experiments per specimen**. A genome or metagenome may now be linked
  to more than one experiment using the same `specimen_id`.

## Fixes

- **Numeric identifiers in spreadsheets**. Fields that Excel stored as numbers are
  now converted to text before validation, so an identifier such as a project code
  entered as `00103` no longer fails validation with a type error.

- **Boolean fields**. Fixed a crash when a field that Excel had already converted
  to a boolean was checked as if it were text.
