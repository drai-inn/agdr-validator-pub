## New and Improved

- **Support for genome `specimen_id` or `metagenomic_id` to be connected to more than one experiment**. The validator now supports one-to-many links.
    - Note: Multiple experiments need to be separated by commas.
    - The TSV generated file for genome or metagenome removes any spaces around the commas for ingestion in AGDR.

- **Update of the manual** with instructions on how to build an executable if needed from this code base.

## Fixes

- **AGDR spreadsheet version checked** and a note is added if it is the not the expected version 

- `schema/node/__init__.py` **updated**

- **validator can now manage** the fact in the genome node that the researcher is only required to provide either the `age` and `age_unit` attributes or the `dev_stage` property.
